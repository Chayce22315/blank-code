# blank code

**cursor, but better. blank money.**

blank code is an autonomous-first coding workspace being designed to turn ideas into working software, with game development as the first-class experience.

## product direction

- a real coding workspace for projects, code, terminal, git, and diagnostics
- a lead agent that plans work and delegates to specialist subagents
- game creation workflows that connect engines, scenes, assets, and build tools
- a playtest-and-repair loop that checks real output instead of assuming generated code works
- model/provider flexibility and free core software
- windows as the primary desktop platform, ios planned, macos coming soon, and linux later

the website describes the product vision and roadmap. it does not claim that all of these capabilities are implemented yet.

## website

the landing page is the root `index.html`, with a small svg favicon. it is a static site with no build step or external runtime dependencies.

## development

open `index.html` in a browser to preview the website locally. the page uses embedded css and lightweight vanilla javascript.
